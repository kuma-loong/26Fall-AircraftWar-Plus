# Feature：自定义背景与连击奖励

## 1. 自定义背景

### 用户入口
- 开始菜单新增背景选择下拉框。
- 默认选项为“按难度默认背景”。
- 用户可将 `png/jpg/jpeg` 图片放入 `src/images/custom/` 后点击“刷新背景列表”载入。

### 运行规则
- 未勾选“按图片尺寸启动窗口”时：
  - 游戏窗口仍固定为 `512x768`；
  - 选中背景会自动缩放到当前窗口尺寸。
- 勾选“按图片尺寸启动窗口”时：
  - 若当前选择的是自定义背景，则窗口宽高使用该图片原始尺寸；
  - 英雄机初始位置、敌机生成区域、Boss 出生点、道具边界、子弹越界判定统一跟随运行时视口。
- 若自定义图片损坏或加载失败，自动回退到当前难度默认背景，不中断游戏。

### 结构调整
- 新增 `GameSettings`：承载难度、背景配置、窗口尺寸策略。
- 新增 `BackgroundProfile`：承载背景名、路径、图片宽高。
- 新增 `GameViewport`：统一管理运行时窗口宽高。
- `GameMainFrame.startGame(...)` 改为接收完整启动配置。
- `ImageManager` 增加自定义背景扫描与背景缩放能力。

## 2. 连击奖励

### 基础规则
- 英雄机子弹连续命中敌机时累积连击数。
- 若在 `45` 帧内继续命中，则连击持续；超时自动清空。
- 英雄机被敌方子弹击中不会清空连击；与敌机相撞时连击立即清空。

### 分数倍率
- `1-4` 连击：`1.0x`
- `5-9` 连击：`1.2x`
- `10-19` 连击：`1.5x`
- `20+` 连击：`2.0x`

### 生存奖励
- 每达到一次 `10` 的倍数连击，英雄机恢复 `10` 点生命值。
- 敌机被击毁时，仍按当前连击倍率结算额外分数。
- 左上角 HUD 在分数与生命值下方追加显示 `COMBO: xN`。
- 右上角显示连击奖励提示（如回血、额外得分），字号与 HUD 保持统一风格。

## 3. 验证与风险控制
- 代码编译检查：
  - `javac -d /tmp/aircraftwar-build $(find src/edu/hitsz -name "*.java")`
- 兼容性控制：
  - `HeroAircraft` 的 DCL 单例保持不变；
  - `Game` 主循环仍使用 Swing `Timer`；
  - 自由尺寸模式只改变视口，不缩放飞机、子弹和道具资源。
