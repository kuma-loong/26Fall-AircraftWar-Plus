# 实验二：简单工厂模式和工厂方法模式

## 任务概述
本次实验要求深入理解简单工厂模式与工厂方法模式的设计意图及结构，结合飞机大战游戏案例，规范绘制两种模式的UML类图，并通过代码实现应用这两种工厂模式。

## 具体任务

### 1. UML类图绘制
- 按照规范绘制简单工厂模式与工厂方法模式的结构类图
- 图中需明确标注设计模式名称
- 自定义合理的类名、属性名及方法名，完整展示模式的实现结构

### 2. 设计模式应用
- **简单工厂模式**：实现道具对象创建
  - 游戏中有5种道具：加血道具、火力道具、超级火力道具、炸弹道具、冰冻道具
  - 所有道具在特定敌机被击毁时按预设概率随机掉落生成
  - 道具生成后以固定速度向屏幕下方移动，英雄机碰撞后自动触发对应效果
  
- **工厂方法模式**：实现敌机对象创建
  - 游戏中有5种敌机：普通敌机、精英敌机、精锐敌机、王牌敌机和Boss敌机
  - 不同类型敌机在生命值、攻击力、移动方式、子弹弹道、得分奖励、生成概率等方面存在明显差异
  - 系统需具备良好的可扩展性，便于未来引入更多新型敌机

### 3. 本次迭代开发目标（Checklist）
1. **UML类图绘制**：按照规范绘制简单工厂模式与工厂方法模式的结构类图
2. **设计模式应用**：完成代码重构，使用简单工厂模式实现道具创建，使用工厂方法模式实现敌机创建
3. **敌机生成**：界面上可观察到4种敌机（Boss敌机本次迭代不要求出场）按周期随机出现
4. **敌机移动**：精锐和王牌敌机向屏幕下方移动，且可左右移动
5. **敌机攻击**：
   - 精锐敌机按设定周期向下直射双排子弹
   - 王牌敌机采用扇形散射弹道，单次同时发射3颗子弹
6. **道具生成**：
   - 精锐敌机、王牌敌机被击毁时按概率随机掉落某一种道具
   - 精锐敌机可掉落4种道具（不含冰冻）中的一种
   - 王牌敌机可掉落全部5种道具中的一种
7. **道具效果**：除加血道具外，其余道具生效时在控制台输出提示信息即可

## 实际完成情况（除 UML）

### 1. 设计模式应用完成
- 已使用**简单工厂模式**实现道具创建：`ItemSimpleFactory`。
- 已使用**工厂方法模式**实现敌机创建：`EnemyFactory` + 各具体敌机工厂。
- `Game` 中移除了敌机与道具的直接 `new` 分支逻辑，改为调用工厂。

### 2. 敌机生成与行为
- 已实现 4 种敌机（普通/精英/精锐/王牌）按周期随机生成。
- Boss 敌机工厂已实现，但本迭代不接入生成（符合清单要求）。
- 精锐与王牌敌机已实现“向下移动 + 左右移动（触边反向）”。
- 精锐敌机已实现双排直射子弹。
- 王牌敌机已实现 3 发扇形散射子弹。

### 3. 道具生成与效果
- 精锐敌机被击毁后按概率掉落 4 种道具之一（不含冰冻）。
- 王牌敌机被击毁后按概率掉落 5 种道具之一（含冰冻）。
- 道具拾取与失效清理链路可用。
- 加血道具真实回血（封顶 `maxHp`）。
- 其余道具生效采用控制台模拟输出：
  - `FireSupply active!`
  - `FirePlusSupply active!`
  - `BombSupply active!`
  - `FreezeSupply active!`

### 4. 首版参数（可在代码常量区调整）
- 敌机生成权重：`Mob 45% / Elite 25% / ElitePlus 20% / Ace 10%`
- 击毁得分：`Mob +10 / Elite +20 / ElitePlus +30 / Ace +50`
- 掉落概率：`ElitePlus 35% / Ace 50%`
